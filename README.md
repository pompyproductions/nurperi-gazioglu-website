# Nurperi Gazioğlu website

Website of Prof. Dr. Nurperi Gazioğlu, live at https://nurperigazioglu.com.

Built with [Astro](https://astro.build) (static output) and Sass, deployed through Netlify.
Primary language is Turkish; English is planned. See `CLAUDE.md` for the roadmap and working rules.

## Commands

```
npm install
npm run dev       # local dev server
npm run build     # static build to dist/
npm run preview   # serve the production build locally
```
